# RUN-GUIDE.md — دليل التشغيل

## الطريقة الأولى: بالنقر المزدوج (لا يحتاج شيئًا)

1. فك ضغط ملف ZIP (أو انسخ مجلد المشروع كاملًا).
2. انقر نقرًا مزدوجًا على `index.html`.
3. يعمل كل شيء محليًا: الرئيسية والأقسام والمواضيع والبحث والأدوات والميزات الشخصية. ملفات القاموس المساندة (المعاني العربية وأنماط النهايات) تُحمّل عند الطلب بوسوم `<script>` كلاسيكية.

متطلبات: متصفح حديث (Chrome/Edge/Firefox/Safari الحديثة). لا إنترنت إلا للخطوط الويب (تعمل بخطوط بديلة بدونه).

## الطريقة الثانية: استضافة ثابتة (لاستخدام القرص أو الجوال)

ارفع محتويات المجلد كما هي إلى أي مستضيف ثابت (Netlify/Vercel/GitHub Pages/Nginx) وافتح `index.html`. لا خادم تطبيق ولا قاعدة بيانات.

## الطريقة الثالثة: خادم محلي

```bash
python3 -m http.server 8000
# أو
npx serve .
```

ثم افتح `http://localhost:8000`.

## للمطوّر: البناء والتعديل

```bash
npm install        # مرة واحدة (esbuild)
npm run build      # ينتج dist/app.js — مطلوب بعد أي تعديل في app/ أو sections/
npm test           # الاختبارات البنيوية (بيانات، روابط، طبقة الميزات، القواميس)
```

- `index.html` يحمّل `dist/app.js` (حزمة IIFE، سكربت عادي — لهذا يعمل من `file://`).
- `index.dev.html` للتطوير: يحمّل وحدات ES مباشرة (يحتاج خادمًا محليًا؛ مطلوب عند التعديل السريع بلا بناء).
- عدّلت شيئًا ولم يظهر؟ تأكد من تشغيل `npm run build` ثم أعد تحميل الصفحة بقوة (Ctrl+Shift+R).

## استكشاف المشكلات

- **شاشة بيضاء**: تأكد أنك تفتح `index.html` (لا `index.dev.html`) من النسخة المبنية، وأن `dist/app.js` موجود.
- **المعاني العربية لا تظهر في محلل الكلمات**: تعمل من `file://`؟ تحقق أن مجلد `public/dict/` منسوخ مع المشروع.
- **الميزات الشخصية لا تحفظ**: وضع التصفح الخاص قد يمنع localStorage (راجع USER-DATA-GUIDE.md).
