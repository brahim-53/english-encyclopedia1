# English Reference Platform — الموسوعة التفاعلية للغة الإنجليزية

منصة مرجعية باللغة العربية (واجهة RTL) مع مصطلحات وأمثلة إنجليزية (LTR)، تتكوّن من قسمين مستقلين:

1. **Fundamentals: النطق والقراءة والتهجئة**
   - **الدرس الأول:** دفتر أصوات الإنجليزية الأمريكية الأصلي، ببحثه وبطاقاته ومراجعه.
   - **14 درسًا تكميليًا:** من وحدات التهجئة والتجمعات إلى بناء الكلمات والاستثناءات وقراءة الكلمات الطويلة واختيار النطق من السياق.
   - **التطبيق:** محلّل الكلمات، «اقرأ وفك»، ومركز التمارين. بحث القسم يصل إلى بطاقات الدفتر والدروس، وزر المراجعة يحدث تقدّم المسار.
2. **Grammar — القواعد الشاملة**
   - الأساسيات (الجملة والعبارة والجملة الفرعية، الفاعل/الفعل/المفعول/المكمل، ترتيب الكلمات، المطابقة)
   - أقسام الكلام كاملة
   - الأزمنة الاثنا عشر بعمق (تعريف، استعمال، متى لا يُستخدم، إشارات، أمثلة صحيحة وخطأ، استثناءات)
   - نظام الأفعال (المساعدة والناقصة، المتعدي/اللازم، أفعال الحالة، الرابطة، المركبة، أنماط V-ing/المصدر، الإنشائية، الناقصات)
   - بناء الجمل، الأسئلة والنفي، الأدوات والمحددات، حروف الجر والروابط
   - القواعد المتقدمة (المبني للمجهول، الشرطية بأنواعها، الموصولة، الكلام المنقول، الانعكاس، التوكيد، الافتراضية، الجمل المشاركية، الحذف، التوازي)
   - تكوين الكلمات (الاشتقاق، التصريف، البادئات، اللواحق، العائلات، المركبات، التحويل) — مع ربط بالنبر والنطق في Fundamentals
   - علامات الترقيم والكتابة بحروف كبيرة
   - أدوات: مقارنة القواعد، مقارنة الأزمنة

## التشغيل

**بالنقر المزدوج على `index.html`** — يعمل مباشرة بلا خادم ولا إنترنت (عدا الخطوط). الصفحة تحمّل `dist/app.js` (حزمة جاهزة) وقاموس النطق كسكربتات عادية، فلا يمنعها المتصفح من `file://`.

**للمطوّر:** الكود المصدري وحدات ES في `app/` و`sections/`. بعد أي تعديل أعد بناء الحزمة:

```bash
npm install
npm run build        # يعيد فهرسة الدفتر وينتج dist/app.js
```

`index.dev.html` يحمّل الوحدات مباشرة (يحتاج خادمًا: `python3 -m http.server 8000`).

الاختبارات الهيكلية (بيانات، روابط، استقلالية القسمين):

```bash
node tests/validate.mjs
```

## التقنيات

- HTML/CSS/JavaScript خالص (vanilla)، بلا إطار عمل وبلا خطوة بناء
- راوتر hash (SPA) + وحدات ES
- بيانات المحتوى ملفات JS مستقلة لكل تصنيف (فصل المحتوى عن العرض)
- خطوط: Amiri + IBM Plex Sans Arabic (عربي)، Gentium Book Plus (لاتيني/IPA)
- قاموس النطق: CMU Pronouncing Dictionary (تقسيم إلى 27 ملف JSON حسب الحرف الأول)
- بيانات مساندة تُحمّل عند الطلب: معاني عربية ومستويات CEFR (9,871 كلمة شائعة) + كلمات أنماط النهايات — IPA فيها محسوب دائمًا من CMUdict
- طبقة ميزات شخصية مستقلة عن المحتوى: `app/features/*` (localStorage بمخطط مفاتيح مُصدَّر `erp.v1.*` مع تدقيق شكلي وتصدير/استيراد)

## الميزات الشخصية (طبقة v4 — اختيارية كلها)

- **مجلتي** (`#/me`): محفوظات، سجل تصفح (آخر 12)، تقدم شخصي (علامات مراجعة يدوية ونسب)، قائمة المراجعة المتباعدة، وتصدير/استيراد بيانات JSON. كلها محلية بلا خادم.
- **أزرار صفحة الموضوع**: احفظ / علّم كمُراجَع / أضف للمراجعة / تمارين الموضوع (إن وجدت)، مع فهرس داخلي وروابط السابق/التالي.
- **البحث الذكي**: بطاقة نمط (ابحث `-tion`) تعرض الموضوع والكلمات الشائعة؛ بطاقة كلمة (ابحث `education`) تعرض IPA من CMUdict والمقاطع والنبر والمعنى العربي وروابط الأنماط.
- **مركز التمارين** (`#/tools/practice-center`): 49 تمرينًا مرتبطة بمواضيع فعلية، منها 14 لمسار النطق والقراءة؛ تصحيح فوري مع شرح وربط عميق عبر `?topic=`.
- **فك ترميز القراءة** (`#/tools/read-decode`): 58 كلمة على 7 مستويات مع تقدم محفوظ.
- **محلل الكلمات المحسّن**: معنى عربي ومستوى CEFR للكلمات الشائعة + روابط أنماط التهجئة داخل الكلمة + ربط عميق `?w=`.
