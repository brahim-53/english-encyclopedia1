# USER-DATA-GUIDE.md — دليل بيانات المستخدم

كل بياناتك الشخصية محفوظة **محليًا في متصفحك فقط** (localStorage)، بلا حساب وبلا خادم وبلا تتبع. لا تغادر جهازك إلا إذا صدّرتها بنفسك.

## ماذا يُحفظ؟

| المفتاح | المحتوى | الحجم التقريبي |
|---|---|---|
| `erp.v1.bookmarks` | قائمة مفاتيح المواضيع المحفوظة | بايتات إلى ~1KB |
| `erp.v1.recentTopics` | آخر 12 موضوعًا زرتها | < 1KB |
| `erp.v1.progress` | علامات «تمت مراجعته» (مفتاح ← طابع زمني) | حسب استعمالك |
| `erp.v1.reviewQueue` | قائمة المراجعة المتباعدة (مواعيد ومراحل) | حسب استعمالك |
| `erp.v1.exerciseResults` | نتائج تمارينك (صحيح/إجمالي لكل موضوع) | حسب استعمالك |
| `erp.v1.prefs` | تفضيلاتك (تفعيل المراجعة، الفواصل بالأيام) | ~100 بايت |
| `erp.decode.<مستوى>` | تقدمك في مستويات أداة فك الترميز | ~50 بايت لكل مستوى |

مفتاح الموضوع بصيغة `section/topic` مثل `grammar/past-simple`. كل قراءة تُدقّق شكليًا؛ البيانات التالفة تسقط بأمان إلى القيم الافتراضية بدل تعطل المنصة.

## التصدير والاستيراد

من صفحة **مجلتي** (`#/me`):

- **تصدير**: زر التصدير ينزّل ملف JSON واحدًا يضم المجموعات الست مع طابع زمني.
- **استيراد**: اختر ملف JSON صالحًا فتُستبدل بياناتك الحالية بمحتواه (بعد تدقيق شكلي لكل مجموعة؛ ما لا يطابق المخطط يُرفض ويبقى الحالي).
- الملف غير الصالح (ليس JSON أو حقول مفقودة) يُرفض برسالة صريحة ولا يمس بياناتك.

## متى تُحذف بياناتك؟

- بمسح بيانات الموقع من المتصفح، أو
- بأزرار «إعادة التعيين» / «إفراغ» في صفحة مجلتي، أو
- لا تُحذف تلقائيًا أبدًا.

## حدود معروفة (موثقة بصراحة)

- **التصفح من نافذتين**: التغييرات في نافذة واحدة تظهر في الثانية بعد إعادة تحميلها (تحديث بين النوافذ غير لحظي).
- **وضع التصفح الخاص**: قد يمنع المتصفح الكتابة في localStorage؛ تستمر المنصة تعمل كاملة، والميزات الشخصية لن تحفظ.
- نسخ احتياطي دوري عبر التصدير إن كانت بياناتك مهمة لك.
