# HOW-TO-ADD-TOPICS.md — كيفية إضافة أو تعديل موضوع

## 1. أضف الموضوع إلى ملف البيانات المناسب

افتح ملف التصنيف داخل القسم المعني، مثل `sections/grammar/data/tenses.js` (أو أنشئ ملفًا جديدًا واستورده في `index.js`).

في قسم النطق والقراءة، أضف درسًا تكميليًا إلى المجموعة المناسبة في `sections/fundamentals/data/path.js` وراجع موقعه في المسار. لا تنشئ نسخة ثانية من البطاقات الصوتية؛ عند الحاجة اربط درسًا بموضع مثل `#/fundamentals/t/ipa-overview#s-29`. ملف `data/notebook-index.js` مشتق من ملف الدفتر تلقائيًا عند البناء ولا يُحرّر يدويًا.

أبسط طريقة: انسخ موضوعًا قائمًا وعدّل محتواه:

```js
G('my-new-topic', 'tenses',        // id فريد + cat مطابق لتصنيف في index.js
  'العنوان بالعربية', 'English Title',
  'ملخص قصير يظهر في نتائج البحث وبطاقة الموضوع.',
  ['كلمات', 'مفتاحية', 'searchable keywords'],   // عربية وإنجليزية — تُغذي البحث
  [
    p('فقرة عربية، مع **تمييز** بالإنجليزية و {{/ˈaɪpiːeɪ/}} للرموز الصوتية.'),
    h('عنوان فرعي'),
    ex({ en: 'I *worked* yesterday.', ar: 'شرح المثال.' }),
    wr(['خطأ شائع.', 'الصواب الصحيح.', 'لماذا الخطأ خطأ؟']),
    tip('ملاحظة للمتعلم.'),
  ],
  ['topic-in-same-section', 'grammar/other-topic', 'fundamentals/suffix-ed'],  // روابط related
  [{ name: 'Cambridge English Grammar Today', url: 'https://dictionary.cambridge.org/grammar/british-grammar/' }],
)
```

في Grammar توجد مساعدات مختصرة في `data/_h.js`: `p, h, list, ol, table, ex, wr, tip, warn, note, cmp` و`SRC.cambridge` وغيرها.

## 2. القيود المهمة

- **id فريد** داخل القسم، و**cat** موجود في `categories` بملف `index.js` للقسم.
- **related** إما `'id'` (نفس القسم) أو `'sec/id'` (القسم الآخر — نص فقط، لا استيرادات).
- **sources**: لا تنسب معلومة لمصدر لم تتحقق منه؛ المصادر الورقية تكتب بلا URL.
- لا تضع المحتوى في ملف واحد عملاق — ملف لكل تصنيف.

## 3. أضف الموضوع إلى تصنيفه

إذا أنشأت ملف بيانات جديدًا، صدّر منه مصفوفة واستوردها في `sections/<section>/index.js` وأضفها إلى `topics` والتصنيف المناسب. أما إذا أضفت موضوعًا إلى ملف قائم فلا يلزم تعديل `index.js` إطلاقًا.

## 4. شغّل الاختبار

```bash
node tests/validate.mjs
```

يتحقق من: وحدة المعرفات، حلول `cat`، حل كل روابط `related`، الاستقلالية بين القسمين، سلامة الترميز، اكتمال كتل المحتوى، وجود المصادر.

## 5. جرّب في المتصفح

```bash
python3 -m http.server 8000
```

افتح `http://localhost:8000/#/grammar/t/my-new-topic` — الموضوع يظهر فورًا في التصفح والبحث دون أي إعادة بناء.

## تعديل الأدوات

الأدوات كائنات `{ id, titleAr, titleEn, render(), mount() }` داخل `sections/<section>/tools/`. عدّل بياناتها (مثل أزواج المقارنة في `grammar-compare.js`) من مصفوفة `PAIRS` مباشرة.


## بعد إضافة موضوع — طبقة الميزات الشخصية (تلقائية غالبًا)

- المحفوظات والسجل والتقدم والمراجعة تعمل مع أي موضوع جديد تلقائيًا (تخزن مفاتيح `section/topic`).
- إن أردت ربط الموضوع بالبحث الذكي: أضف النمط في `app/features/relations.js` (ENDING_TOPICS/DIGRAPHS/TEAMS) — `npm test` يتحقق أن المرجع موجود فورًا.
- إن أردت تمارين للموضوع: أضفها إلى `app/features/practice-data.js` بنفس مواصفات الأنواع الأربعة مع شرح `why` — `npm test` يتحقق من المعرف والنوع والشرح.
- ثم دائمًا: `npm run build` (إن عدّلت شيئًا خارج ملفات بيانات القسم) و`npm test`.
