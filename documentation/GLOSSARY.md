# GLOSSARY.md — المسرد المصطلحي للمنصة

مسرد موحد للمصطلحات المستعملة في واجهة المنصة ووثائقها، لتثبيت الاستعمال العربي عبر كل الصفحات.

## مصطلحات النطق والقراءة (Fundamentals)

| المصطلح | English | تعريف قصير |
|---|---|---|
| الصوت/الفونيم | Phoneme | أصغر وحدة صوتية تميز المعنى (44 في GA) |
| الجرافيم | Grapheme | حرف أو مجموعة أحرف تمثل صوتًا واحدًا (sh, ck, tion) |
| النبر | Stress | بروز صوت مقطع على غيره (يُرمز ˈ قبله) |
| المقطع | Syllable | وحدة إيقاعية؛ أنواعها المغلق والمفتوح |
| المقطع المغلق | Closed syllable | ينتهي بساكن فتقصر الحركة (hat /hæt/) |
| المقطع المفتوح | Open syllable | ينتهي بحركة فتُنطق كاسمها (go /oʊ/) |
| الحركة المتحكم بها r | R-controlled vowel | r تلي الحركة فتغير جودتها (car /kɑr/) |
| الدفتونج | Diphthong | حركة تنزلق من صوت لآخر (/ɔɪ/, /aɪ/) |
| الشوا | Schwa /ə/ | الحركة غير المنبورة المخففة في المقاطع الضعيفة |
| التضعيف | Doubling | تضعيف الساكن النهائي قبل لواحق (run → running) |
| الصوت المفخم (Flap) | Flapping /ɾ/ | t بين حركتين تلفظ كطاء خفيفة في GA (water) |
| ARPAbet | ARPAbet | ترميز صوتي حرفي لقاموس CMU (K AE T) |
| IPA | International Phonetic Alphabet | الأبجدية الصوتية الدولية المعروضة للمستخدم |
| GA | General American | النطق الأمريكي العام — المرجع الصوتي الوحيد للمنصة |
